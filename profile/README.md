## What we do

We make tools that are genuinely capable but don't feel like work to use. "Powerful tools that feel like toys" isn't a slogan, it's a design constraint: approachable on the first minute, deep when you need it.

- **Apps.** Cross-platform mobile and web apps, sold once, with no subscription where we can avoid it.
- **Contracts.** Scientific data visualisation, environmental analytics and academic tooling, from a physics and scientific-computing background.
- **Entangled Art.** The craft side: crochet, bobbin lace, tessellation and workshops, with the same ethos. [entangledart.co.uk](https://entangledart.co.uk)

## How we build

- **Clarity over cleverness.** Opinionated software beats endless configuration, and complexity gets hidden behind good design rather than removed.
- **Incremental over rewrite.** A surgical fix beats a rewrite.
- **Honest scope.** No bloatware, no corporate design language, no subscription-everything.
- **Boring, dependable foundations.** Vue 3, Pinia, TypeScript and SCSS, with Capacitor for cross-platform mobile and native SwiftUI where Apple-only APIs earn it. Hosted on Cloudflare. iOS first, Android kept within reach.
